# NEEDORA Mobile App — V1 Demo

## Product principle
The mobile app is consumer-first. It is not a compressed copy of the public website. The patient flow is optimized around one question: **Cosa ti serve?**

## Patient navigation
1. Cerca
2. Preferiti
3. Prenotazioni
4. Messaggi
5. Profilo

### Home
- NEEDORA brand + Match Point
- Service search with canonical suggestions
- Current location
- Quick filters: Today, At home, Online, Nearest
- Available today carousel
- Categories
- NEEDORA Home block for at-home services

### Search results
- Service + location summary
- Filters: Today, Nearest, Price, Mode
- Mode values: All / In person / At home / Online-Video
- List / Map switch
- Sponsored results are clearly labeled
- Cards show distance, indicative price, rating, modes and first availability

### Public provider profile
- Cover image
- Verified profile marker
- Rating, distance and availability
- Description
- Services and indicative prices
- Team
- Reviews
- Location
- Persistent booking CTA

### Booking flow
1. Mode
2. Professional or first available
3. Date and time
4. Review and confirm
5. NEEDORA Match Point success animation

### Personal area
- Favorites
- Bookings
- Messages
- Profile/preferences

## Professional mobile experience
The professional tools live inside the authenticated account and are not exposed on the consumer home.

Bottom navigation:
1. Today
2. Calendar
3. Bookings
4. Activity
5. Profile

Activity modules:
- Services
- Team
- NEEDORA Demand
- Analytics
- AI Reception
- NEEDORA Ads
- Clients
- Plan

The mobile app prioritizes day-to-day actions. Advanced configuration stays better suited to the web dashboard.

## Visual system
- Navy #102A43
- Teal #0F746C
- Mint #9ED7C9
- Cloud #F7FBFA
- Manrope
- Match Point used for loader, verification, highlights and success states
- Large comfortable type, rounded cards, minimal micro-animation
- No continuous decorative motion
